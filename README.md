# 📊 Student Performance Analysis

A complete Python Data Analytics project that analyzes student performance using real-world educational data. This project demonstrates data cleaning, exploratory data analysis (EDA), visualization, and insight generation using Python.

---

## 🚀 Features

- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Student Performance Insights
- Correlation Analysis
- Professional Data Visualizations
- Export of Cleaned Dataset
- Beginner-Friendly Python Code
- GitHub Ready Project Structure

---

## 🛠️ Technologies Used

- Python 3.x
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## ▶️ How to Run

### Clone Repository

```bash
git clone https://github.com/your-username/student-performance-analysis-python.git
```

### Move to Project Folder

```bash
cd student-performance-analysis-python
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Project

```bash
python analysis.py
```

## 📌 Sample Insights

- Students with higher study hours generally score better.
- Attendance has a positive impact on academic performance.
- Students with educated parents tend to achieve slightly higher average marks.
- Strong positive correlation exists between study time and final score.
